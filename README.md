# Iron & Roots

Landing page for Iron & Roots, a UK online fitness membership. Strong habits. Real results.

**Live site:** https://kxngcxzz.github.io/Iron-roots/

- Main page (dark): https://kxngcxzz.github.io/Iron-roots/
- Backup design (brand palette): https://kxngcxzz.github.io/Iron-roots/light.html

The site is published from the `main` branch with GitHub Pages, so changes merged into `main` go live automatically after a minute or two.

## Files

- `index.html` – main landing page
- `light.html` – backup design in the brand palette
- `assets/` – coach photos
- `brand/` – logo files and colour tokens
- `CLAUDE.md` – project notes, brand rules and placeholders still to fill
